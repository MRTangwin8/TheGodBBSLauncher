# 开发状态与路线图

更新日期：2026-10-26 · 当前版本：v0.3.0（预发布）

## 当前状态

神权论坛启动器是一个可以日常试用的内测版本，主要功能都已实现：
- 原版安装、Java 管理、三种账号登录、游戏启动；
- 加载器一键安装、资源中心、整合包导入导出、崩溃分析；
- 主题中心。

下一阶段的重点是**可靠性**：先把现有功能在各平台、各游戏版本上验证扎实，再做插件、自动更新这类新功能。

## 已知限制

- **安装包未签名**：Windows SmartScreen、macOS Gatekeeper 会拦截，绕过方法见 README。
- **macOS**：提供 Apple 芯片版和 Intel 版。在 Apple 芯片上运行很老的游戏版本（依赖旧 LWJGL natives）尚未适配，Intel 版没有这个问题。
- **钥匙串回退**：系统钥匙串不可用时（例如 Linux 没有运行 Secret Service），加密密钥会存成配置目录里的普通文件，保护效果减弱。
- **第三方整合包**：导入时会拦截常见的 `..` 路径穿越，但对 Windows 保留文件名、符号链接 / junction 等情况的防护还不完整。请只导入来源可信的整合包。
- **日志脱敏**只作用于启动器界面里显示的内容，不会改写 Minecraft 或模组自己写到磁盘的日志。分享原始日志前请自己检查一遍。
- **CurseForge**：少数模组的作者关闭了第三方下载，只能去网页手动下载。
- 安装和导入任务暂时不能取消，也不防止重复启动同一个任务。

## 路线图

### 近期：可靠性与安全

1. 真实启动验收矩阵：原版 1.8.9 / 1.12.2 / 1.20.1 / 最新版，以及 Fabric / Quilt / Forge / NeoForge。覆盖启动失败、手动结束、崩溃诊断、再次启动等情况。
2. 统一外部元数据和整合包的路径安全检查：库路径、继承 ID、Windows 保留名称、符号链接 / junction。
3. 加固钥匙串回退：密钥文件写入失败时明确提示；Unix 上限制文件权限。
4. 安装 / 导入任务支持取消，增加互斥和中断恢复。
5. macOS 和 Linux 真机测试。

### 中期：发布与维护

1. 安装包代码签名。
2. 应用内自动下载并安装更新：需要先生成更新签名密钥（私钥只放在 GitHub Secrets，不进仓库），用 Tauri updater 校验签名。目前已经有"发现新版本时弹窗提示"，但安装仍要用户自己去发布页下载。
3. 维护变更记录（CHANGELOG）。

### 远期：新功能

- 实例独立设置：每个版本单独设置 Java、内存、参数。
- 模组更新检查与批量更新。
- 服务器列表：显示延迟、在线人数，一键加入。
- 存档管理：备份、恢复、截图浏览。
- 自定义按钮与首页快捷操作。
- 插件系统：导入的第三方内容默认不允许执行脚本。
